# YAMAGUCHI Hair Styler

Адаптивная презентация фена-стайлера YAMAGUCHI по макету Figma. Реализованы три слайда с отдельными композициями для компьютеров и мобильных устройств.

## Технологии

- HTML5 и семантическая разметка
- SCSS (Sass)
- JavaScript без сторонних UI-фреймворков
- Vite для локальной разработки и сборки
- Web Animations API для анимации переходов
- Playwright: Chromium, Firefox и WebKit для проверок в браузере

## Запуск

Требуется Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Vite выведет адрес локального сервера.

Для сборки и просмотра готовой версии:

```bash
npm run build
npm run preview
```

Результат сборки находится в папке `dist/`.

## Управление

**На компьютере (ширина от 768 px):** прокрутка колёсиком мыши или тачпадом переключает слайды с вертикальной анимацией. Одновременно поворачивается колесо навигации. Слайды можно выбирать нажатием на иконки. Поддерживаются клавиши стрелок, Page Up / Page Down, Home и End.

**На мобильных устройствах (ширина менее 768 px):** три слайда расположены последовательно и прокручиваются обычным вертикальным жестом. Колесо навигации скрыто. Размеры элементов изменяются пропорционально ширине экрана с помощью контейнерных единиц `cqw`.

При включённой настройке уменьшения движения переходы выполняются без анимации.

## Проверка

Автоматическая проверка выполняется в GitHub Actions при изменениях в ветке `main` и при создании pull request.

Проверяются:

- Production-сборка и загрузка ресурсов.
- Мобильные размеры 320, 360, 375, 390, 414, 430, 480, 600 и 767 px.
- Последовательность слайдов, их размеры и переносы текста.
- Отсутствие горизонтальной прокрутки в мобильном режиме.
- Десктопные размеры 768, 1024, 1280, 1440 и 1920 px.
- Переключение слайдов мышью, кликами и клавиатурой.
- Состояние активной иконки навигации.
- Переключение между мобильным и десктопным режимами.
- Работа с настройкой `prefers-reduced-motion`.
- Отсутствие ошибок JavaScript в консоли.
- Стабильность ключевых сценариев в Chromium, Firefox и WebKit.

Скриншоты сохраняются как артефакты GitHub Actions.

Для локального запуска браузерных проверок:

```bash
npm ci
npm install --no-save --package-lock=false playwright@1.56.1
npx playwright install chromium firefox webkit
npm run build
node tests/mobile-layout.mjs
node tests/desktop-layout.mjs
node tests/cross-browser.mjs
python -m pip install Pillow
python tests/test_pixel_comparison.py
```

## Макет

[Hair Styler — Figma](https://www.figma.com/design/59pZHAGKortikkSiLRRZvP/Hair_Styler_TEST--Copy---Copy-?node-id=0-1)

Для обеих версий использованы три основные композиции. Дополнительные скрытые слайды исходного документа не входят в реализацию.

## Ресурсы

Для текста используется свободно распространяемый шрифт Montserrat. Лицензия размещена в `public/fonts/OFL.txt`.

Оригинальный макет использует Euclid Circular A преимущественно в начертании SemiBold. Это коммерческий шрифт: файлы Euclid не включены в публичный репозиторий. Для точного воспроизведения его метрик требуется отдельно лицензированная версия с поддержкой кириллицы и соответствующими весами; пробный или локальный файл Regular не заменяет SemiBold.

Графика подготовлена для страницы презентации. Все изображения слайдов хранятся в WebP и SVG. Мобильные иллюстрации и остальные графические ресурсы сжаты в WebP без потери видимых пикселей; модель второго десктопного слайда отдельно уменьшена до необходимого разрешения.

Montserrat хранится в WOFF2 с сохранением вариативного начертания и набора символов. Условия распространения шрифта приведены в `public/fonts/OFL.txt`.

## Проверка совпадения с Figma

Попиксельное сравнение запускается отдельно от функциональных тестов. Для него нужны шесть эталонных PNG, экспортированных из Figma в масштабе 1×. Автоматически считать собственные скриншоты приложения эталоном нельзя.

Названия эталонов: `desktop-1.png`, `desktop-2.png`, `desktop-3.png` (1240 × 800 px), `mobile-1.png` (320 × 717 px), `mobile-2.png` (320 × 936 px), `mobile-3.png` (320 × 920 px).

```bash
python -m pip install Pillow
python tools/compare-figma.py --figma tests/figma-reference --browser test-results
```

В `test-results/diff` сохраняются наложения, карты расхождений, трёхпанельные сравнения и `summary.csv`. Скрипт читает браузерные кадры из `test-results/mobile/` и `test-results/desktop/`. Текст может отличаться из-за лицензированного шрифта оригинального макета и особенностей рендеринга платформы.

Файлы эталонов добавляются локально и не включены в репозиторий.
