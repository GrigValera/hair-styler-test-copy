# YAMAGUCHI Hair Styler

Адаптивная презентация из трёх слайдов по [макету Figma](https://www.figma.com/design/59pZHAGKortikkSiLRRZvP/Hair_Styler_TEST--Copy---Copy-?node-id=0-1).

**Стек:** HTML, SCSS, JavaScript, Vite. Без UI-фреймворков.

## Запуск

Node.js 22+.

```bash
npm ci
npm run dev
```

Production-сборка: `npm run build`, просмотр: `npm run preview`.

## Управление

- **От 768 px:** переходы между слайдами прокруткой, кнопками бокового колеса и клавиатурой (стрелки, Page Up/Down, Home, End).
- **До 767 px:** три слайда в обычном вертикальном потоке; размеры адаптируются через `cqw`.
- Настройка `prefers-reduced-motion` отключает анимацию переходов.

## Структура

- `index.html` — разметка трёх слайдов.
- `src/scripts/` — переключение слайдов и анимация колеса.
- `src/styles/` — общие и десктопные стили; `mobile/` — стили по каждому слайду.
- `public/` — изображения, SVG-иконки и шрифт.
- `tests/` — проверки мобильной и десктопной версий в Chromium. Запускаются через GitHub Actions.

## Шрифты

**Основной — Montserrat:** его WOFF2-файл и лицензия OFL включены в проект.

**Euclid Circular A — второй (резервный) в CSS:** объявлен только через `local()`. **Файлов Euclid в репозитории и production-сборке нет** из-за коммерческой лицензии. Если шрифт установлен на компьютере, браузер может использовать его как запасной; обычно отображается Montserrat. В оригинальном макете преимущественно используется Euclid Circular A SemiBold, поэтому начертания текста могут отличаться.
